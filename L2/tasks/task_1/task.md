# L2 / Task 1 — Git basics

Самостоятельное задание. Никакого стартового кода — только последовательность
действий, которую нужно проделать руками, чтобы закрепить базовые операции с git.

Прежде чем начать: создай отдельный приватный репозиторий на GitHub для этого
задания (см. правила именования в корневом [README.md](../../../README.md)).

## Что нужно сделать (по порядку)

1. Создай на своей локальной машине новую папку под проект (название на твой вкус).
2. Проинициализируй в этой папке git-репозиторий.
3. Настрой репозиторий:
   - добавь `README.md` с парой предложений о том, что это за проект;
   - добавь `.gitignore` и впиши туда пару паттернов (например, файлы логов,
     `.DS_Store` и т.д.);
   - опционально — добавь что-то ещё на своё усмотрение (LICENSE, структура папок...).
4. Создай в папке несколько разных файлов, часть из которых должна попадать под
   правила `.gitignore`, часть — не должна.
5. Добавь файлы в staging (`git add`).
6. Убедись через `git status`, что файлы, подходящие под `.gitignore`, в staging
   не попали.
7. Убери из staging один из уже добавленных файлов (не удаляя сам файл).
8. Убери одно из правил из `.gitignore` — так, чтобы ранее игнорируемый файл
   стал видимым для git. Проверь через `git status`, что это сработало.
9. Сделай коммит.
10. Внеси ещё какие-то изменения (поправь README, добавь/удали файл) и сделай
    второй коммит. Повтори это ещё раз — должно получиться минимум 3 коммита.
11. Запушь репозиторий на GitHub.
12. Удали локальную папку с проектом **целиком**.
13. Восстанови проект — сделай `git clone` репозитория с GitHub в новую папку и
    убедись, что вся история коммитов и все файлы на месте.

## Как сдавать

Когда всё проделано и запушено — дай преподавателю доступ Read к репозиторию
(см. корневой [README.md](../../../README.md)).
