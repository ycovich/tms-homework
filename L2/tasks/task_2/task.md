# L2 / Task 2 — Merge conflict

В этой папке лежит [main.go](main.go) — маленькая программа на Go, которая печатает вопрос-сканворд. Ответ на вопрос
написан справа от строки комментарием — это подсказка тебе, а не часть кода.

Функция `printAnswer()` пока пустая — её и предстоит собрать через merge.

## Подготовка

1. Создай отдельный приватный репозиторий на GitHub для этого задания (см. правила именования в
   корневом [README.md](../../../../README.md)).
2. Склонируй его на свою локальную машину, скопируй туда `main.go` и `setup_branches.sh` из этой папки, закоммить их в
   `main`.
3. Запусти скрипт:

   ```bash
   bash setup_branches.sh
   ```

   Скрипт создаст от ветки main две новые ветки — `vowels` и `consonants` — в каждой из них независимо допишет функцию
   `printAnswer()`: в `vowels` появятся гласные буквы ответа, в `consonants` — согласные. После работы скрипта ты
   вернёшься на основную ветку.

## Задание

Слей ветки `vowels` и `consonants` в основную ветку (порядок и способ — через
`vowels` в `consonants`, или наоборот, или обе по очереди в основную — не важен, важен результат). Обе ветки меняют одну
и ту же функцию `printAnswer()`, так что при merge возникнет конфликт — разреши его так, чтобы буквы в
`printAnswer()` шли в правильном порядке.

## Как сдавать

Запушь итоговую основную ветку (с влитой историей обеих веток) на GitHub и дай преподавателю доступ Read к репозиторию
(см. корневой
[README.md](../../../../README.md)).
