# L7 / Task 11 — Цензор

Чат-бот печатает сообщения пользователей. Нужно, чтобы запрещённые слова заменялись звёздочками: `ты дурак` →
`ты *****`. Функцию, которая печатает сообщения, менять **нельзя**: она уже написана и пишет в `io.Writer`:

```go
func printText(w io.Writer, lines []string) {
    for _, line := range lines {
        fmt.Fprintln(w, line)
    }
}
```

Решение — встать **между** ней и терминалом. Ты напишешь тип `Censor`, который реализует `io.Writer`: получает текст,
заменяет плохие слова и передаёт результат дальше, в `os.Stdout`.

```
printText ──► Censor ──► os.Stdout
```

## Зачем эта задача

- Увидеть главную силу интерфейсов. `printText` ничего не знает про цензуру, но работает с ней, потому что `Censor`
  умеет `Write`. Новое поведение добавлено, а старый код не изменился ни на строчку.
- Освоить приём «обёртка». `Censor` хранит следующий `io.Writer` в поле и сам тоже `io.Writer`. Так в стандартной
  библиотеке устроены сжатие (`gzip.Writer`) и буферизация (`bufio.Writer`).
- Попрактиковаться с `defer`: итог печатается в конце, а объявляется сразу после создания цензора.
- Посмотреть на ваш лексикон обсценной лексики :)

## Ввод

1. Первая строка — запрещённые слова через пробел. Строка может быть пустой: тогда запрещённых слов нет.
2. Дальше до конца ввода — строки сообщений. Строки могут быть пустыми, а сообщений может не быть совсем.

Все слова — из строчных русских или английских букв. В сообщениях слова разделены ровно одним пробелом, знаков
препинания нет, пробелов в начале и в конце строки нет. Ввод всегда корректный.

## Вывод

Каждая строка сообщения, где каждое запрещённое слово заменено звёздочками: столько `*`, сколько в слове **букв**
(`дурак` → `*****`). Заменяется только слово целиком: если запрещено `дурак`, слово `дурачок` остаётся как есть.

В конце — строка `--- заменено слов: <сколько слов заменено>`.

## Пример

Ввод:

```
дурак плохой
ты дурак и плохой
хороший день

плохой плохой дурачок
```

Вывод:

```
ты ***** и ******
хороший день

****** ****** дурачок
--- заменено слов: 4
```

## Как решать

```go
type Censor struct {
    Out      io.Writer       // куда передавать текст дальше
    Banned   map[string]bool // запрещённые слова
    Replaced int             // сколько слов заменено
}
```

1. Напиши метод `func (c *Censor) Write(p []byte) (int, error)`. `fmt.Fprintln` вызывает его один раз на каждую строку,
   и в `p` приходит вся строка вместе с `\n` в конце. Метод делает три вещи:
    - разбивает `string(p)` на слова и заменяет запрещённые, увеличивая `c.Replaced`;
    - записывает результат в `c.Out`: слова через пробел и `\n` в конце;
    - возвращает `len(p), nil`. По договору `io.Writer` метод сообщает, сколько байтов **из `p`** он принял, а не
      сколько записал сам.
2. Функцию `printText` возьми из условия без изменений.
3. В `main`: прочитай запрещённые слова в map и сообщения в слайс, создай `c := &Censor{Out: os.Stdout, Banned: …}`,
   объяви `defer` с печатью итога и вызови `printText(c, lines)`.

## Подсказки

- `strings.Fields(string(p))` делит строку на слова и сам отбрасывает `\n`. Обратно склеивает
  `strings.Join(words, " ")`. Для пустой строки `Fields` вернёт пустой слайс, `Join` — пустую строку, и останется просто
  `\n`.
- Звёздочки: `strings.Repeat("*", len([]rune(w)))`. Считай руны, а не байты: в `дурак` 5 букв, но 10 байтов.
- Вот так `defer` **не сработает**:

  ```go
  defer fmt.Println("--- заменено слов:", c.Replaced)
  ```

  Аргументы `defer` вычисляются сразу, в момент объявления. Тогда `c.Replaced` ещё 0, и в конце напечатается 0. Нужно
  отложить анонимную функцию: она прочитает счётчик при вызове, в конце `main`.

  ```go
  defer func() {
      fmt.Println("--- заменено слов:", c.Replaced)
  }()
  ```

## Проверь себя

1. Почему в `printText` передают `c` типа `*Censor`, а не `Censor`?
   <details><summary>Ответ</summary>

   `Write` объявлен с получателем-указателем, а такие методы есть только у `*Censor`. Значит, `io.Writer` реализует
   `*Censor`, как `&sb` для `strings.Builder` на лекции. И это не формальность: с получателем-значением `c.Replaced++`
   увеличивал бы копию, и итог всегда был бы 0.
   </details>

2. Как отправить отцензурированный текст не в терминал, а в строку?
   <details><summary>Ответ</summary>

   Поменять одно поле: `var sb strings.Builder` и `Out: &sb`. Ни `printText`, ни `Censor` менять не нужно — им всё
   равно, куда писать. Точно так же можно писать в файл или в сетевое соединение.
   </details>
