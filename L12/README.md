# L12 — ДЗ к уроку 12: DataShifter, конвертер JSON → CSV

Одно задание, но уже похожее на настоящее приложение: программа читает JSON-файл, превращает его в CSV и записывает в
лог, что делает. Рассчитывай примерно на 3 часа на базовую часть. Только стандартная библиотека Go. Нужен твой
модуль `shop` из ДЗ L11 (без ★): **для базовой части — его `go.mod` и `logging.New`**, для ★ — ещё `shop/middleware` и
`shop/server`.

| Задание                                        | Что тренируем                                                                                                                                       |
|------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------|
| [task_1 — DataShifter](tasks/task_1/task.md)   | `io.Reader` и `io.Writer`, файлы, `encoding/json` и `encoding/csv`, `io.MultiWriter`, переменные окружения, подключение packages L11 через `replace` |
| ★ там же — приём JSON по сети                 | `net/http`: `r.Body` и `ResponseWriter` напрямую в функцию; сервер, middleware и лог — готовые packages из L11                                        |
| ★★★ там же — безопасная запись `output.csv` | временный файл, `Sync` и `os.Rename`: старый файл не пропадает при ошибке                                                                           |

В `task.md` есть «Как решать», «Подсказки», «Зачем эта задача» и «Проверь себя» с ответами под спойлером. Образец
входного файла лежит рядом с заданием: [`input.json`](tasks/task_1/input.json).

## Что можно использовать

Всё, что было на уроках 5–12. Из библиотек — только стандартная и packages `shop/…` из своего ДЗ L11.

## Что должно быть в репозитории

```
ivan-petrov/
  L11/
    task_1/             ← модуль shop из прошлого ДЗ
  L12/
    task_1/
      go.mod            ← module task1, require shop и replace на ../../L11/task_1
      main.go
      converter.go      ← ConvertJSONtoCSV
      atomic.go         ← WriteFileAtomic (только если делаешь ★★★)
```

Каждая папка задания — отдельный модуль: `cd L12/task_1 && go mod init task1`. Как подключить `shop` из L11 — в начале
`task.md`.
`input.json`, `output.csv` и `app.log` в репозиторий не клади.

## Как проверяется

Проверка собирает `L12/task_1` вместе с твоей папкой `L11/task_1`: `replace` должен указывать на неё.

1. Функция `ConvertJSONtoCSV` вызывается напрямую: CSV сравнивается с правильным **символ в символ**, `rows` — с числом
   строк. При некорректном JSON — ошибка, `rows` равно `0`, и в `w` не записано ничего.
2. Программа запускается во временной папке с закрытыми `input.json`:
   - `output.csv` совпадает с правильным символ в символ, старый `output.csv` перезаписывается;
   - каждая строка `app.log` есть и в консоли; без `LOG_FORMAT` строки текстовые (`time=… level=…`), с
     `LOG_FORMAT=json` каждая строка — JSON-объект; есть строка `INFO` с атрибутом `rows`;
   - второй запуск дописывает `app.log`, а не стирает;
   - нет `input.json` или он некорректный: код выхода `1` и строка уровня `ERROR` в консоли и в `app.log`.
3. Для ★ программа запускается с `MODE=server`, `ADDR` и `LOG_FORMAT=json`: `POST /convert` отвечает `200`, CSV,
   `Content-Type: text/csv…` и `X-Request-ID`; на некорректный JSON — `400` и строка `ERROR` в логе; в логе есть
   строки запросов с `path`, `status`, `duration`; после `SIGTERM` программа завершается с кодом `0`; в папке нет других
   файлов, кроме `app.log`.
4. Для ★★★ `input.json` портится между запусками: `output.csv` остаётся прежним, временных файлов в папке нет; если
   первый же запуск упал, `output.csv` не появляется.
5. Оценка ставится по базовой части; ★ и ★★★ отмечаются отдельно.
6. Код читает преподаватель: нет внешних библиотек, packages L11 подключены через `replace`, а не скопированы, в
   `ConvertJSONtoCSV` нет файлов и логов, JSON не читается целиком через `io.ReadAll`.
