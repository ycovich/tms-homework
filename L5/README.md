## Как читать ввод

Ввод во всех задачах — одна или несколько строк. Каждое значение (число, имя, текст) — на своей отдельной строке. Читай
их рецептом со слайда «Ввод с клавиатуры»: сканер создаётся **один раз**, а `in.Scan()` + `in.Text()` вызываются для
каждой строки:

```go
in := bufio.NewScanner(os.Stdin) // один раз в начале main

in.Scan()
first := in.Text() // первая строка целиком

in.Scan()
second := in.Text() // вторая строка
```

Число из строки — через `strconv.Atoi`. Если в условии написано «ввод всегда корректный», ошибку можно не проверять:

```go
n, _ := strconv.Atoi(first)
```

Если написано «ввод нужно проверить» — проверяй и при ошибке выходи из `main`:

```go
n, err := strconv.Atoi(first)
if err != nil {
fmt.Println("Ошибка: нужно целое число")
return // ранний выход из main
}
```

Не смешивай в одной программе `fmt.Scanln` и `bufio.Scanner`: сканер читает ввод наперёд, и `Scanln` после него ничего
не получит.

## Как читать примеры

Примеры в условиях часто даны таблицей. Каждая строка таблицы — отдельный пример:

- колонки «Ввод: …» — строки ввода сверху вниз, в порядке колонок слева направо;
- колонки «Вывод: …» — строки вывода по порядку (если колонка вывода одна — это одна строка);
- обратные кавычки `` ` `` вокруг значений вводить и печатать не нужно.

| Ввод: `n` | Ввод: `k` | Вывод: 1-я строка | Вывод: 2-я строка |
|-----------|-----------|-------------------|-------------------|
| `3`       | `14`      | `4`               | `2`               |

Этот пример значит: программа получает на вход две строки, `3` и `14`, и печатает две строки, `4` и `2`.

## Как проверить себя

Запусти программу и введи строки руками (каждую — Enter):

```bash
cd L5/task_2
go run .
```

Или подай весь ввод сразу. В терминале macOS / Linux и в **Git Bash** на Windows (в PowerShell русские буквы при
передаче через `|` ломаются — там вводи руками):

```bash
printf '3\n14\n' | go run .
```

Здесь `\n` — перевод строки, то есть две строки ввода: `3` и `14`. Сравни вывод с примерами из `task.md`.

## Как проверяется

1. Программа запускается на наборе тестов, он шире примеров в `task.md`. Вывод сравнивается с правильным символ в
   символ — печатай ровно то, что в разделе «Вывод», без `Введите число:` и лишних пробелов.
2. Код читает преподаватель. Если в условии сказано, **как** решать (через `switch`, через указатель, через метку),
   решение «в обход» не засчитывается, даже если тесты прошли.
