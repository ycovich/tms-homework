# L5 / Task 5 — Каждый раз вдвое

На первую клетку шахматной доски кладут 1 зерно, на вторую — 2, на третью — 4, и так далее: на каждую следующую клетку
вдвое больше зёрен, чем на предыдущую. Всего на доске 64 клетки.

Сколько зёрен лежит на клетке номер `n`? И сколько всего зёрен на клетках с 1-й по `n`-ю?

Обе величины считай в цикле `for`, без `math.Pow` и сдвигов `<<`. Числа здесь огромные: для `n = 64` они не помещаются в
`int`, поэтому подумай, какой тип данных нужно выбрать.

## Ввод

Одна строка — номер клетки `n`, 1 ≤ `n` ≤ 64. Ввод всегда корректный.

## Вывод

Две строки: сколько зёрен на клетке `n`, затем сколько всего зёрен на клетках с 1-й по `n`-ю.

## Примеры

| Ввод | Вывод: 1-я строка     | Вывод: 2-я строка      |
|------|-----------------------|------------------------|
| `3`  | `4`                   | `7`                    |
| `10` | `512`                 | `1023`                 |
| `64` | `9223372036854775808` | `18446744073709551615` |
