# L5 / Task 1 — Знакомство

Программа получает имя и город пользователя и здоровается с ним.

Никаких вопросов вроде `Как тебя зовут?` не печатай: программа выводит только две строки из раздела «Вывод».

## Ввод

Две строки: имя, затем город. И имя, и город могут состоять из нескольких слов: `Анна Мария`, `Нижний Новгород`.

## Вывод

Две строки:

```
Привет, <имя>!
Твой город: <город>
```

## Примеры

Ввод:

```
Анна
Минск
```

Вывод:

```
Привет, Анна!
Твой город: Минск
```

---

Ввод:

```
Анна Мария
Нижний Новгород
```

Вывод:

```
Привет, Анна Мария!
Твой город: Нижний Новгород
```

## Подсказки

- Строку целиком, вместе с пробелами, читает `bufio.Scanner`: пример — в [L5/README.md](../../README.md).
  `fmt.Scanln` для этой задачи не подойдёт: на вводе `Анна Мария` он прочитает только `Анна`.
- `fmt.Println` ставит пробел между своими аргументами. Чтобы `!` встал вплотную к имени, удобнее использовать
  `fmt.Printf`:
  `fmt.Printf("Привет, %s!\n", name)`.
