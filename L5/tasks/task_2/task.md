# L5 / Task 2 — Поровну на всех

`n` школьников делят `k` яблок поровну. Яблоки не режут: то, что не делится поровну, остаётся в корзинке.

Сколько яблок достанется каждому школьнику и сколько останется в корзинке?

## Ввод

Две строки: число `n`, затем число `k`. 1 ≤ `n` ≤ 1000, 0 ≤ `k` ≤ 1 000 000. Ввод всегда корректный.

## Вывод

Две строки: сколько яблок у каждого школьника, затем сколько яблок осталось в корзинке.

## Примеры

| Ввод: `n` | Ввод: `k` | Вывод: 1-я строка | Вывод: 2-я строка |
|-----------|-----------|-------------------|-------------------|
| `3`       | `14`      | `4`               | `2`               |
| `5`       | `5`       | `1`               | `0`               |
| `4`       | `3`       | `0`               | `3`               |

То есть для первого примера программа получает на вход строки `3` и `14`, а печатает строки `4` и `2`.

## Подсказки

- `/` для двух целых чисел отбрасывает дробную часть: `14 / 3` — это `4`. Остаток от деления — `%`: `14 % 3` — это `2`.
- Ошибку от `strconv.Atoi` здесь можно не проверять: `n, _ := strconv.Atoi(in.Text())`.
