# L5 / Task 8 ★ — Сдвиг букв (необязательная)

Задача со звёздочкой: её можно не делать. Она для тех, кому хочется поработать со строками и рунами.

Зашифруй текст сдвигом: каждую букву английского алфавита (`a`–`z` и `A`–`Z`, 26 букв) замени на букву, которая
стоит в алфавите на `k` позиций дальше. За `z` снова идёт `a`, то есть алфавит замкнут в круг. При `k = 3`: `a` → `d`,
`x` → `a`, `z` → `c`.

Заглавные буквы остаются заглавными, строчные — строчными. Всё остальное — пробелы, цифры, знаки препинания, русские и
любые другие буквы — не меняется.

Обходи саму строку циклом `for … range` по ней — без преобразования в `[]rune` или `[]byte` и без пакетов `strings` и
`unicode/utf8`.

## Ввод

Две строки: непустой текст (в нём могут быть пробелы и русские буквы), затем число `k`, 0 ≤ `k` ≤ 26. Ввод всегда
корректный.

## Вывод

Одна строка — зашифрованный текст.

## Примеры

| Ввод: текст           | Ввод: `k` | Вывод                 |
|-----------------------|-----------|-----------------------|
| `OMG`                 | `5`       | `TRL`                 |
| `Let's eat, Grandma!` | `21`      | `Gzo'n zvo, Bmviyhv!` |
| `Привет, World!`      | `3`       | `Привет, Zruog!`      |
