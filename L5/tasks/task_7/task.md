# L5 / Task 7 — Кодовый замок

У замка три колёсика с цифрами от 0 до 9. Известно, что все три цифры кода **разные**.

Взломщик перебирает коды по порядку: `012`, `013`, …, `019`, `021`, `023`, … — то есть как числа от `000` до `999`,
но пропускает те, где есть одинаковые цифры (`000`, `001`, `010`, `011`, … он даже не пробует). Каждый проверенный
код — одна попытка.

С какой попытки взломщик откроет замок?

Перебирай коды тремя вложенными циклами — по одному на каждую цифру. Коды с одинаковыми цифрами пропускай через
`continue`. Как только код найден, выходи сразу из **всех** циклов через `break` с меткой. Ответ должен получаться
перебором: `return` внутри циклов и подсчёт номера попытки формулой не засчитываются.

## Ввод

Три строки — первая, вторая и третья цифра кода. В каждой строке одна цифра от 0 до 9. Все цифры разные. Ввод всегда
корректный.

## Вывод

Одно число — номер попытки, на которой замок откроется.

## Примеры

| Ввод: 1-я цифра | Ввод: 2-я цифра | Ввод: 3-я цифра | Вывод |
|-----------------|-----------------|-----------------|-------|
| `0`             | `1`             | `2`             | `1`   |
| `0`             | `1`             | `3`             | `2`   |
| `1`             | `0`             | `2`             | `73`  |
| `9`             | `8`             | `7`             | `720` |
