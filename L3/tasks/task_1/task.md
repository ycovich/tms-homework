# L3 / Task 1 — Linux-квест

Задание выполняется в Ubuntu, которая запускается в Docker-контейнере. В первой части нужно поработать с пользователями
и группами. Во второй - настоящий квест: нужно найти части ключа, которые прошлый предыдущий админ спрятал в системе.

Если чувствуешь, что нагрузка слишком большая, есть **_упрощённый вариант задания_** - онлайн-терминалы.
Например, https://coddy.tech/playground/terminal. Поработай с онлайн-терминалом самостоятельно - практикуй базовые
команды: **ls**, **cd**, **cat**, **echo**, **rm**, **find**, **which**, **pwd**, **tar**, и так далее. Квест выполнишь
тогда, когда будешь чувствовать себя уверенно, задание ниже - без дедлайна

## Подготовка

1. Установи Docker:
    - **macOS и Windows:** [Docker Desktop](https://www.docker.com/products/docker-desktop/). На Windows установщик
      попросит включить WSL 2: соглашайся и перезагрузи компьютер.
    - **Linux:** [Docker Engine](https://docs.docker.com/engine/install/). Чтобы запускать `docker` без `sudo`, выполни
      `sudo usermod -aG docker $USER` и перезайди в систему.
2. Проверь, что Docker работает: команда `docker run hello-world` должна напечатать приветствие.
3. Склонируй этот репозиторий и перейди в папку задания:

   ```bash
   git clone https://github.com/ycovich/tms-homework.git
   cd tms-homework/L3/tasks/task_1
   ```

## Запуск

Вместо `ivan` подставь своё имя латиницей – так будут звать твоего пользователя в системе.

|                       | macOS / Linux             | Windows (PowerShell)                                               |
|-----------------------|---------------------------|--------------------------------------------------------------------|
| Первый запуск         | `./start.sh ivan`         | `powershell -ExecutionPolicy Bypass -File .\start.ps1 ivan`        |
| Вернуться в контейнер | `./start.sh`              | `powershell -ExecutionPolicy Bypass -File .\start.ps1`             |
| Начать с нуля         | `./start.sh --reset ivan` | `powershell -ExecutionPolicy Bypass -File .\start.ps1 -Reset ivan` |

При первом запуске скачивается образ системы, это займёт пару минут. Когда появится строка `ivan@tms-lab:~$`, можно
работать.

- Пароль для `sudo`: `1234`. Пока вводишь пароль, символы на экране не появляются, так и задумано.
- Выйти из контейнера: `exit`. Все изменения сохранятся до следующего запуска.
- Если что-то сломалось и не чинится, начни с нуля (последняя строка таблицы).

## Часть 1. Пользователи и группы

1. Создай пользователя `alice` с домашней папкой и задай ей пароль.
2. Создай пользователя `bob` с домашней папкой и задай ему пароль.
3. Удали `alice` вместе с домашней папкой.
4. Дай `bob` права администратора: добавь его в группу `sudo`.
5. Создай группу `devs` и добавь в неё `bob`.
6. Создай папку `/srv/project`. Владелец root, группа `devs`, права `770`
   (владелец и группа могут всё, остальные ничего).
7. Войди под `bob` (`su - bob`) и создай в `/srv/project` любой файл. Потом вернись к своему пользователю (`exit`) и
   проверь, что тебе самому в `/srv/project` заглянуть нельзя.

Проверить себя можно командой `check-users`.

Пригодятся команды `adduser`, `userdel`, `usermod`, `groupadd`, `chown`, `chmod`, `su`, `id`. Как ими пользоваться,
смотри в `man <команда>` или `<команда> --help`.

> Если добавил `bob` в группу, а права не появились, выйди из сессии `bob` и войди заново.
> Список групп пользователя обновляется только при входе.

## Часть 2. Квест

Прошлый админ уволился и оставил ключ от сервера, разбитый на три части. Части спрятаны в системе, и каждая
подсказывает, что искать дальше. Начни с `README.md` в своей домашней папке.

- Нашёл часть ключа: допиши её в файл `~/key.txt` отдельной строкой и выполни `found`. Команда проверит часть и
  запомнит, что ты продвинулся.
- Не понимаешь, что делать дальше: набери `lost`. Команда напомнит задание и скажет, что искать сейчас. Как искать, она
  не подскажет, это часть задания.
- Все три части найдены: собери из них ключ через дефис и выполни `unlock КЛЮЧ`. Если ключ верный и первая часть задания
  сделана, `unlock` выдаст токен и сохранит отчёт в `report.txt`.

## Как сдавать

1. Скопируй отчёт из контейнера к себе на компьютер. Нужную команду для этого ты увидишь после ввода команды `unlock`,
   но вообще выглядит она так:

   ```bash
   docker cp linux-quest:/home/your_username/report.txt .
   ```

2. Создай репозиторий по правилам из корневого [README.md](../../../README.md), например
   `l3-ivan-petrov-task1`, положи в него `report.txt` и сделай push.
3. Дай преподавателю доступ к репозиторию.

Кроме токена, в отчёт попадает история всех команд, которые ты вводил в терминале linux :)
