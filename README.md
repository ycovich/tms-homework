# TMS Homework

Здесь лежат условия домашних заданий. Решения ты пишешь в **своём** репозитории — одном на весь курс [ОДНОМ].

## Где что лежит

```
L{N}/                  — урок номер N (L5, L6, ...)
  README.md            — что нужно сделать по уроку и как сдать
  tasks/
    task_1/
      task.md          — условие задания
      ...              — стартовый код, если он нужен
    task_2/
      task.md
```

Начинай с `L{N}/README.md` нужного урока, затем читай `task.md` каждого задания.

## Твой репозиторий

Теперь у тебя должен быть ОДИН приватный репозиторий на GitHub на весь курс. Решения всех уроков клади в него вот так:
каждый урок в своей папке

```
ivan-petrov/              ← твой репозиторий
  README.md
  L5/
    task_1/
      go.mod              ← module task1
      main.go
    task_2/
      go.mod              ← module task2
      main.go
  L6/
    task_1/
      go.mod
      main.go
```

- Репозиторий называется твоими ИМЕНЕМ и ФАМИЛИЕЙ латиницей через дефис: `ivan-petrov`.
- Папки — строго `L{N}` (заглавная L) и `task_{M}` (с подчёркиванием), как в этом репозитории.
- Каждая папка задания — отдельный проект со своим `go.mod`. Имя модуля — `task{M}`: `task1`, `task2`, ...
- Запуск задания: `cd L5/task_1 && go run .`
- Только стандартная библиотека Go: без `go get` и строк `require` в `go.mod`.
- Не клади в репозиторий скомпилированные программы и всякий мусор, не относящийся к заданию.

PS Старые репо можешь не удалять, но смысла в них особо нет

## Как завести репозиторий (один раз)

Команды ниже — для терминала macOS и Linux. **На Windows все команды выполняй в Git Bash**: он установился вместе с Git
во втором уроке

1. Открой [github.com/new](https://github.com/new) и создай репозиторий:
    - **Repository name** — имя и фамилия латиницей через дефис, например `ivan-petrov`;
    - видимость **Private**;
    - включи **Add README**, чтобы репозиторий сразу можно было склонировать.
2. Дай доступ преподавателю: в репозитории **Settings → Collaborators → Add people** → `ycovich` → отправь приглашение.
   Это делается один раз, доступ сохранится для всех уроков.
    - GitHub даёт коллаборатору личного репозитория право записи — так и должно быть. Я ничего не меняю в твоём
      репозитории, только смотрю.
3. Склонируй репозиторий. Ссылку скопируй с зелёной кнопки **Code** на странице репозитория:

   ```bash
   git clone https://github.com/твой-логин/ivan-petrov.git
   cd ivan-petrov
   ```

   Репозиторий приватный, поэтому git попросит войти в GitHub. **Пароль от аккаунта GitHub здесь не подойдёт.**
   Обычно открывается окно входа через браузер — войди в нём. Если git спрашивает пароль прямо в терминале, вставь
   вместо пароля токен: GitHub → **Settings → Developer settings → Personal access tokens** → создай токен с доступом к
   репозиториям (scope `repo`).
4. Один раз на компьютере скажи git, кто ты. Почта — та, что в аккаунте GitHub:

   ```bash
   git config --global user.name "Иван Петров"
   git config --global user.email "ivan@example.com"
   ```

5. Пришли преподавателю ссылку на репозиторий в телеграм  [!!!].

## Как сделать задание

Из корня своего репозитория создай папку задания и проект в ней (пример — первое задание пятого урока):

```bash
mkdir -p L5/task_1
cd L5/task_1
go mod init task1
```

Рядом с появившимся `go.mod` создай `main.go` и пиши решение в нём. Проверь, что программа запускается: `go run .`

Когда задание готово — закоммить и отправь на GitHub:

```bash
cd ../..                 # обратно в корень репозитория
git add .
git commit -m "L5: task_1"
git push
```

## Как проверяются задания

Задания проверяются _автоматически_. Программа собирается и запускается на закрытом наборе тестов, он шире примеров в
`task.md`. Вывод программы сравнивается с правильным **символ в символ**:

- печатай ровно то, что написано в разделе «Формат вывода»: без фигни вроде `Введите число:`, лишних пробелов, пустых
  строк, пояснений, комментариев;
- читай ввод только с клавиатуры (стандартный ввод), без файлов или других некорректных аргументов;
- каждая строка вывода должна заканчиваться переводом строки (новой строкой);
- если не совпал хотя бы один символ (например, русская «с» вместо латинской `c`), тест не пройден.
