# TMS Homework

Здесь лежат только **описания** заданий — код и решения студенты пишут и хранят в своих собственных репозиториях.

## Структура репозитория

```
L{N}/                      — папка урока (L2, L3, L4, ...)
  tasks/
    task_1/
      task.md              — описание задания
      (доп. файлы)         — стартовый код, скрипты и т.д., если нужны
    task_2/
      task.md
      main.go
      ...
```

Номер `N` в `L{N}` соответствует номеру урока. Внутри каждого урока задания пронумерованы по порядку (`task_1`,
`task_2`, ...).

## Как выполнять и сдавать задание

1. Найди нужный урок и задание: `L{N}/tasks/task_{M}/task.md`. Прочитай `task.md` — там описано, что нужно сделать, и
   какие файлы (если таковые есть) нужны для старта.
2. Для **каждого** задания создай отдельный **приватный** репозиторий на GitHub. Название репозитория должно однозначно
   определять урок, тебя как студента и номер задания, например:

   ```
   l2-michael-jackson-task1
   l2-michael-jackson-task2
   ```

   (шаблон: `l{N}-{имя_фамилия}-task{M}`)
3. Выполни задание в этом репозитории, следуя инструкциям из `task.md`.
4. Когда задание готово — открой Settings → Collaborators and teams в своём репозитории и выдай доступ **Read (viewer)**
   преподавателю:
   GitHub-аккаунт `<TODO: укажи свой GitHub username>`.
5. Сообщи преподавателю, что репозиторий готов к проверке.

## Важно

- Один репозиторий = одно задание. Не смешивай несколько заданий в одном репозитории.
- Репозитории с решениями — приватные. Доступ преподавателю даётся точечно, через Collaborators, а не через публикацию
  репозитория.
- Формат сдачи ДЗ может изменяться в зависимости от содержания самого ДЗ
- Дедлайны НЕ ПРИВЯЗАНЫ к датам проведения занятий и назначаются преподавателем (мной) отдельно для каждого домашнего
  задания
